# 🎙️ محرك استنساخ الصوت (Voice Clone Engine)

محرك مجاني ومفتوح المصدر لاستنساخ الأصوات وتحويل النص إلى كلام بصوت متحدث معيّن، انطلاقاً من مقطع صوتي قصير. يعمل **محلياً** أو على **GitHub سحابياً**، **بدون أي مفاتيح API** أو اشتراكات.

## 📖 نبذة عن المشروع

يعتمد المشروع على نموذج **XTTS-v2** المفتوح المصدر (من Coqui)، وهو نموذج يقوم بما يُسمى **الاستنساخ الفوري (Zero-Shot Voice Cloning)**: أي أنه لا يحتاج إلى تدريب على صوت الشخص، بل يكفيه مقطع مرجعي من 6 إلى 30 ثانية ليولّد أي نص بنبرة الصوت نفسها وأسلوبه.

يضيف المشروع فوق النموذج طبقة تجعله عملياً وسهل الاستخدام:

- معالجة تلقائية للمقطع المرجعي لرفع جودة الاستنساخ.
- واجهة ويب بالعربية، وواجهة سطر أوامر، وواجهة برمجية بسيطة.
- إعداد جاهز للتشغيل على GitHub سحابياً.
- إقرار بالموافقة قبل أي توليد.

## ⚙️ كيف يعمل

```
مقطع مرجعي ──► تنظيف وتطبيع ──┐
                               ├──► XTTS-v2 ──► ملف WAV بصوت المتحدث
النص + اللغة ─────────────────┘
```

1. يُحمَّل المقطع المرجعي ويُحوَّل إلى قناة واحدة بتردد 24kHz.
2. يُقصّ الصمت من البداية والنهاية، ويُحدَّد الحد الأقصى بـ30 ثانية، ويُطبَّع مستوى الصوت.
3. يستخرج النموذج بصمة صوتية من المقطع، ثم يولّد الكلام للنص المطلوب بتلك البصمة.

## 🧰 المتطلبات

- **Python 3.10 إلى 3.12** (يُفضَّل 3.11)
- مساحة قرص: حوالي **5 جيجابايت** (النموذج ≈ 1.8GB + المكتبات)
- ذاكرة: **8GB RAM** على الأقل
- **ffmpeg** و**libsndfile** على النظام
- بطاقة **NVIDIA** اختيارية لكنها تسرّع التوليد كثيراً، ويعمل المشروع على المعالج فقط بشكل أبطأ

## 💻 التثبيت والتشغيل محلياً

### 1) تثبيت أدوات النظام

```bash
# Ubuntu / Debian
sudo apt-get update && sudo apt-get install -y ffmpeg libsndfile1

# macOS
brew install ffmpeg libsndfile

# Windows: ثبّت ffmpeg من https://ffmpeg.org وأضفه إلى PATH
```

### 2) إنشاء بيئة افتراضية وتثبيت الاعتمادات

```bash
python -m venv .venv
source .venv/bin/activate        # على Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

> لو لديك بطاقة NVIDIA، ثبّت نسخة torch المناسبة لـ CUDA من [pytorch.org](https://pytorch.org) قبل الخطوة أعلاه.

### 3) التشغيل

```bash
python app.py
```

افتح الرابط الذي يظهر في الطرفية (عادةً `http://localhost:7860`).

> ⏳ أول تشغيل يحمّل النموذج تلقائياً (≈1.8GB). بعدها يعمل بدون إنترنت.

## ☁️ التشغيل على GitHub Codespaces

الطريقة الأسهل للحصول على واجهة كاملة بدون تثبيت شيء على جهازك.

1. أنشئ مستودعاً جديداً على GitHub (**اجعله خاصاً** إن كنت سترفع أصواتاً).
2. ارفع كل ملفات المشروع مع المجلدين المخفيين `.devcontainer/` و`.github/`.
3. اضغط الزر الأخضر **Code** ثم تبويب **Codespaces** ثم **Create codespace on main**.
4. انتظر التثبيت التلقائي (بضع دقائق). سيعمل التطبيق ويُفتح المنفذ **7860** تلقائياً.
5. إن لم يُفتح المتصفح، افتح تبويب **Ports** واضغط على رابط المنفذ 7860.

**ملاحظات:**

- الحساب المجاني يمنح حوالي **120 ساعة معالج شهرياً**، والجهاز ذو 4 أنوية يستهلكها بضعف المعدل.
- Codespaces يتوقف عند الخمول، فاحذف الـ Codespace عند الانتهاء لتوفير الحصة.
- لا يوجد GPU، فالتوليد على المعالج وأبطأ من الزمن الحقيقي.

## 🤖 التوليد الدفعي عبر GitHub Actions

مناسب لتوليد ملف صوتي واحد بدون واجهة.

1. أنشئ مجلد `samples/` وارفع إليه مقطعك المرجعي، مثل `samples/voice.wav`.
2. من تبويب **Actions** اختر **Voice Clone (batch)** ثم **Run workflow**.
3. املأ الحقول:
   - **text**: النص المراد نطقه
   - **ref**: مسار المقطع داخل المستودع
   - **lang**: رمز اللغة (`ar`، `en`، ...)
   - **consent**: اكتب `yes` للإقرار بأن لديك إذن صاحب الصوت
4. بعد انتهاء التشغيل، حمّل `cloned-voice` من قسم **Artifacts** في صفحة التشغيل.

> النموذج يُخزَّن مؤقتاً (cache) لتسريع التشغيلات اللاحقة. مهلة المهمة 45 دقيقة.

## ⌨️ الاستخدام عبر سطر الأوامر

```bash
python app.py \
  --text "مرحباً بكم في محرك استنساخ الصوت" \
  --ref samples/voice.wav \
  --lang ar \
  --out result.wav \
  --yes-i-have-consent
```

| الوسيط | الوصف | الافتراضي |
|---|---|---|
| `--text` | النص المراد نطقه (بدونه تُفتح الواجهة) | — |
| `--ref` | ملف أو عدة ملفات صوتية مرجعية | — |
| `--lang` | رمز اللغة | `ar` |
| `--out` | مسار ملف الإخراج | `output.wav` |
| `--speed` | سرعة الكلام (0.7 - 1.4) | `1.0` |
| `--temperature` | التنوع (أقل = أثبت، أعلى = أكثر تعبيراً) | `0.65` |
| `--yes-i-have-consent` | إقرار بإذن صاحب الصوت (**إلزامي**) | — |

**مثال بعدة مقاطع مرجعية:**

```bash
python app.py --text "Hello world" --ref a.wav b.wav c.wav --lang en --yes-i-have-consent
```

## 🎯 نصائح لأعلى دقة

- استخدم مقطعاً **واضحاً بين 10 و30 ثانية**، بدون موسيقى خلفية أو ضوضاء أو صدى.
- سجّل بميكروفون جيد وفي غرفة هادئة، فجودة المدخل تحدد جودة المخرج.
- **ارفع عدة مقاطع** من المتحدث نفسه بنبرات مختلفة قليلاً لنتيجة أغنى.
- اجعل **لغة المقطع المرجعي قريبة من لغة النص**، فالاستنساخ عبر اللغات قد يضعف الشبه أو يضيف لكنة.
- اكتب النص **بعلامات ترقيم صحيحة**، فهي تتحكم بالوقفات والنبرة. وللعربية فالتشكيل الخفيف في المواضع الملتبسة يحسّن النطق.
- قسّم النصوص الطويلة جداً إلى فقرات وولّدها على دفعات.
- إن كان الصوت غير مستقر أو فيه تشوهات فخفّض **التنوع** إلى 0.5 تقريباً.
- إن كان فيه تكرار أو تلعثم فارفع `repetition_penalty` في الكود.

## 🛠️ حل المشكلات الشائعة

| المشكلة | الحل |
|---|---|
| `OSError: libsndfile` أو أخطاء قراءة الصوت | ثبّت `libsndfile1` و`ffmpeg` على النظام |
| خطأ يتعلق بـ `torchcodec` عند تحميل الصوت | شغّل `pip install torchcodec`، أو ثبّت إصدارات أقدم من `torch` و`torchaudio` (مثل 2.5.x) |
| توليد بطيء جداً | طبيعي على المعالج؛ استخدم GPU أو Google Colab أو قلّل طول النص |
| `CUDA out of memory` | قصّر النص، أو أغلق البرامج الأخرى، أو شغّل على المعالج |
| الصوت الناتج لا يشبه الأصل | حسّن جودة المقطع، وأضف مقاطع أخرى، وطابق اللغة |
| نطق عربي خاطئ لبعض الكلمات | أضف تشكيلاً للكلمة، أو أعد صياغة الجملة |
| خطأ بسبب إصدار مكتبة `transformers` | ثبّت الإصدار الذي تطلبه مكتبة `coqui-tts` في صفحتها الرسمية |
| فشل تحميل النموذج | تأكد من الاتصال بالإنترنت في أول تشغيل ومن وجود مساحة كافية |
| الواجهة لا تُفتح في Codespaces | افتح تبويب **Ports** وتأكد من أن المنفذ 7860 مُعاد توجيهه |

- ❌ عدم نشر محتوى مولَّد على أنه تسجيل حقيقي؛ والأفضل الإفصاح بأنه صوت مصنَّع.

يتطلب المشروع إقراراً بالموافقة قبل كل توليد، والمسؤولية القانونية عن الاستخدام تقع على المستخدم وحده.

## 📜 الرخصة والشكر

- نموذج **XTTS-v2** مرخّص برخصة **Coqui Public Model License (CPML)** وهي للاستخدام **غير التجاري**. راجع الرخصة الكاملة قبل أي استخدام تجاري.
- مكتبة **coqui-tts** (النسخة المصانة من مشروع Coqui TTS) مرخّصة برخصة MPL-2.0.
- الواجهة مبنية على **Gradio**، والمعالجة الصوتية على **PyTorch / torchaudio**.
- يُرجى إضافة رخصة لكودك الخاص (مثل MIT) في ملف `LICENSE` إن أردت مشاركته.
